# 🧭 Professional Profile

<img align="right" width="280" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif">

I'm an **Information Systems Engineering undergraduate at SLIIT** focused on building a career in:

**Business Analysis → Systems Analysis → Enterprise Architecture**

My primary interest is understanding how **business strategy, processes, information, applications, and technology** work together to create effective information systems.

I approach problems from both perspectives:

**Business Perspective**

> What problem are we solving?

**Systems Perspective**

> What system should support the business?

**Architecture Perspective**

> How should the solution fit into the wider enterprise?

I also use **data analysis and software development** to validate requirements, understand problems, prototype solutions, and communicate effectively with technical teams.
